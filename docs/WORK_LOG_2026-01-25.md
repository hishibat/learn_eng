## DBマイグレーション

### 新テーブル: daily_mode_completions
```sql
CREATE TABLE daily_mode_completions (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES auth.users(id),
  study_date DATE NOT NULL,
  study_mode TEXT NOT NULL CHECK (study_mode IN ('flashcard', 'quiz', 'spelling')),
  completed_at TIMESTAMPTZ DEFAULT NOW(),
  word_count INTEGER DEFAULT 0,
  UNIQUE(user_id, study_date, study_mode)
);
```

### RLSポリシー
- `Users can manage own records` - auth.uid() = user_id

### 新規インデックス
- `idx_daily_mode_user_date` on daily_mode_completions(user_id, study_date)
- `idx_mistake_records_word_date` on mistake_records(word_id, created_at)
- `idx_mistake_records_user_date` on mistake_records(user_id, created_at)

## 技術的なポイント

### 練習モード vs SRSモード
- **SRSモード（今日の学習）**: 復習対象の単語をSRSで管理、next_reviewを更新
- **練習モード**: 全単語から学習可能、SRSは更新せず間違いのみ記録

### モード完了の仕組み
1. 学習セッション完了時に`markModeCompleted()`を呼び出し
2. `daily_mode_completions`に日付・モードを記録
3. ホーム画面・学習画面でチェックマークを表示

### 間違い振り返り機能
- `useMistakeReview`フックで日付フィルター付き履歴取得
- 単語別サマリー（間違い回数順）と時系列履歴の2ビュー
- 詳細モーダルから練習モードへ遷移可能
